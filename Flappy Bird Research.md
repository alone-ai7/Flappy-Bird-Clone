
A Development Study of a 2D game using GODOT
              	3.5.3: A Flappy Bird Clone



CHAPTER 1: THE PROBLEM AND ITS BACKGROUND


Abstract

This study focuses on the development of a 2D arcade game entitled “Flappy Bird” using the Godot Engine 3.5.3 and GDScript. The primary objective of this game is to learn the fundamentals of 2D game development as a solo developer. The game follows a simple core loop where the player taps to make a bird flap and avoid obstacles to achieve a high schore. Godot 3.5.3 was chosen as the game engine due to its lightweight nature and suitability for 2D projects. The development process includes game design, implementation of mechanics such as gravity and collision, and exporting the game to PC and mobile platforms. The expected outcome of this study is a working game and improved understanding of Godot 2D and GDScript fo future projects.


Background of the Study

Game development is a growing field that allows individuals to express creativity while learning tehcnical and problem-solving skills. However, for beginners, starting can be difficult due to lack of knowledge, limited resources, and the high system requirements of modern game engines.

Godot Engine 3.5.3 was selected for this study because it is lightweight and can run efficiently on low to mid-range computers. Unlike other commercial game engines that require high-end hardware, Godot provides an accessible entry point for aspiring developers with limited PC resources. Its open-source nature and focus on 2D development also make it ideal for learning fundamental game development concepts.

“Flappy Bird” was chosen as the project for this study because of its simple mechanics and suitability for beginners. The game’s core loop involves player input, gravity, and collision detection, which are essential concepts in 2D game development. By developing this game, the researcher aims to gain a deep understanding of both the mechanics of a game engine and the design of the game itself. This project also serves to document the learning journey and challenges encountered during development, particularly in overcoming the limitations of hardware and experience as a solo beginner developer.


Statement of the Problem

As a beginner game developer, the main challenges encountered are understanding code logic, game design principles, and starting development with limited resources.

This study aims to answer the following question:

1.1 How can a beginner overcome difficulties in coding and game design when learning 2D game development using Godot 3.5.3?

1.2 What are the step-by-step processes and core mechanics involved in developing a simple 2D arcade game such as “Flappy Bird”?

1.3 How can this development journey be documented to serve as guide for other beginners who want to start with 2D games before moving to 3D?

 CHAPTER 2: REVIEW OF RELATED LITERATURE


Flappy Bird as a 2D Arcade Game. Flappy Bird is a mobile arcade game developed by Dong Nguyen and 
released in 2013. The game gained worldwide popularity due to its simple gameplay and high difficulty level. The objective is to control a bird and navigate it through gaps between green pipes by tapping 
the screen to make it flap.

Flappy Bird is commonly used as a beginner project in game development 
because it demonstrates three fundamental 2D game concepts:

1.  Physics Simulation - Constant gravity and player-controlled lift
2.  Procedural Generation - Infinite obstacles with random spacing
3.  Collision Detection and Scoring - Game over state and score tracking

The simplicity of its mechanics makes it ideal for learning core game loops, input handling, and state management.


Godot Engine 3.5.3 for 2D Development

Godot Engine is a free, open-source, and cross-platform game engine released under the MIT license. Version 3.5.3 was selected for this study because it is a Long-Term Support version that is stable and 
optimized for 2D game development.

Compared to engines like Unity and Unreal Engine, Godot has a smaller file size and lower system requirements, making it accessible for developers with limited PC resources. It uses GDScript, a language similar to Python, which is beginner-friendly.

The Node and Scene system in Godot allows for modular development, where game objects such as the Bird, Pipes, and UI can be developed as separate scenes and reused. This structure supports the needs of this project as a solo beginner developer.
